# 第三十四章 招贤司开张


第二天一早，唐缺正式挂牌。

没有锣鼓，没有鞭炮。他让人找了一块旧木板，刷了一层薄薄的白灰，用墨汁写了三个字：招贤司。然后挂在客栈隔壁那间空铺子的门楣上。

铺子里的陈设也很简单……一张方桌，两把椅子。桌上一本空白的册子，一支笔。墙角靠着一个笸箩，里面放着几块干粮和一壶凉开水……唐缺说这叫"待贤之礼"。

宁观潮站在门口看了一会儿。那块招牌上的字歪歪扭扭的，像是用左手写的。

"这字是你写的？"

"是啊。"唐缺从身后探出头来，颇为骄傲地端详了一番，"怎么样？很有风骨吧？"

"像是螳螂在上面爬了一圈。"

"……艺术这东西，殿下你不懂。"

宁观潮没有继续打击他。

招贤的告示贴出去了。唐缺沿着城南到城西的主街贴了六七张，还特意在城西棚户区那边多贴了几张。告示上写得很简单……"黑石城招贤，凡有一技之长者，均可报名"，下面是客栈隔壁的地址。

然后就是等。

第一天上午，来了一个人。

是个瘸腿的老兵。五十多岁，左腿膝盖以下没有了，装了一截木棍当假肢。他拄着一根自制的拐杖，站在招贤司门口，犹豫了很久才走进去。

唐缺热情地招呼他坐下："老丈，您有一技之长？"

老兵沉默了一会儿："我以前在边军养过马。"

"养马好！养马是正经手艺。您养过多久？"

"十来年。"

"那您怎么不干了？"

老兵低头看了一眼自己的左腿。

唐缺没有继续追问。他在册子上记了一笔。

"行，您记个名。有活干的时候我让人通知您。"

老兵点了点头，站起来，拄着拐走了。临走时他回头看了唐缺一眼，嘴唇动了动，像是想说什么，最终没说出口。

宁观潮站在隔壁客栈门口，把这一幕看在眼里。

他走过去。

"刚才那个老兵，你认识？"

"不认识。黑石城这种地方，从边军退下来的人不少，真正能养好伤的没几个。他那条腿是刀伤留下来的……不是摔的，是被人砍的。"

宁观潮没有说话。他看了一眼那个老兵消失的方向。

接下来两天，来的人寥寥无几。

第二天来了两个人……一个挑着担子走街串巷的布贩子，说他会说几句草原话，年轻时跟赤狄商人做过买卖。另一个是个四十来岁的汉子，自称会养猪，在城西养了几头瘦得皮包骨的黑猪。

第三天更离谱。

来了一个抱着孩子的女人。她站在招贤司门口，看着那块写歪了的招牌发了一会儿呆。唐缺迎上去，热情地问她有什么手艺。女人沉默了一会儿，抬头看了他一眼。

"我不是来应征的。"

唐缺的笑容僵了一下。

"我是来讨口吃的……孩子两天没吃上饱饭了。"

唐缺没有赶她走。他到隔壁端了一碗粥，又拿了两块干粮，递给那个女人。女人接过去，蹲在门槛边，一口一口地喂孩子。

唐缺蹲在门口，看着那个女人和孩子。

他转过头，朝客栈的方向喊了一句。

"殿下……"

宁观潮从窗边探出头来。

"你看，我就说嘛……光坐在这儿等人上门，招不来什么正经人。"

宁观潮没有回答。他看了一眼那个蹲在门槛边喂孩子的女人，又看了一眼贴在墙上的招贤告示。

"那你打算怎么办？"

唐缺站起来，拍了拍裤腿上沾的灰。

"出去找。"

宁观潮看了他一眼。

唐缺说得很自然，不像临时起意，倒像是早就在心里盘算过了。

"黑石城就这么大。能干活的人我都知道在哪儿。城西那个铁匠铺里的老铁匠，打了一辈子铁，快七十了还在抡锤子。城东那个茶馆里有个账房先生，以前在州府衙门里做过事，因为得罪了人被赶回来了。在南边山脚下的一个村子里，还有一户打猎的父子俩，箭法不比陆沉舟差多少。"

他一个一个掰着手指头数。

"但他们不会自己走到招贤司来。他们不信这东西。"

唐缺把折扇展开，往领口里一插。

"得我去请。"

宁观潮沉默了一会儿。

"要请多久？"

"给我七天。"

唐缺说完，转身走了。他的脚步比平时快了几分，方向是城西。那家铁匠铺的屋顶，在午后的阳光里冒出一缕黑烟。

宁观潮站在窗口，看着那个背影穿过灰扑扑的街道。

福伯在他身后擦桌子，低声问了一句："少爷，那个唐缺……真能把人请来？"

宁观潮想了想。

"他那张嘴……"

"能唬住刀疤马的人，请几个匠人，问题不大。"
