# 第三十二章 新来的麻烦


米铺的事还没解决，城外来了人。

永平关方向。一队人马，六七个人，骑着军马，穿着边军的号衣。领头的是个三十出头的汉子，身形魁梧，脸膛赤红，腰间挂着一把制式长刀。他带着人从官道上过来，在城门口勒住了马。

守门的兵卒看见这阵势，连问都没敢问，赶紧让开了路。

那队人马径直穿过城门，沿着主街走了一段，在县衙门口停了下来。

领头的汉子翻身下马，大步走上台阶，拍了拍县衙的大门。

县丞从里面探出头来，看见这个人的打扮，脸色变了一下。

"这位军爷是……？"

"永平关，校尉张横。"那人声音粗犷，像是习惯了在风沙里喊话，"奉都尉之命，来黑石城办事。你们的领主呢？"

县丞擦了一下额头上的汗："六殿下在城南客栈。"

张横没有多问。他转身，重新翻身上马，带着人朝城南去了。

客栈门口。

宁观潮正在大堂里坐着，面前摊着一张顾青瓷昨晚送来的粮价记录表。门外的马蹄声由远及近，在客栈门口停住了。

他没有站起来。

张横推开门走进来的时候，看见一个穿旧青衫的年轻人坐在桌边，手里端着一碗茶。那人抬起头看了他一眼，目光平静，没有站起来迎接的意思。

张横确定了……这就是那个废太子。

他在门口站了一下，然后走到宁观潮对面，也不等人招呼，自己拉了一张椅子坐下。

"六殿下，末将永平关校尉张横。奉都尉之命前来。"

宁观潮没有放下茶碗："什么事？"

"北境边军今冬军需未足。永平关按朝廷规制，有权在边境属地征调粮草。"张横从怀里掏出一份文书，往桌上一放，"这是征调文书。按例，黑石郡需拨粮八百石，送往永平关。"

宁观潮没有去看那份文书。他端着茶碗，看着张横。

"文书上盖的是哪个衙门的印？"

张横的表情僵了一下。

"征调文书按例由都尉签署即可。都尉的印，够用了。"

"够用？"宁观潮放下茶碗，"朝廷的征调，需要州府的批复。边军自行征调，只适用于战时紧急状态。现在是战时吗？"

张横的目光沉了一下。

宁观潮站起来，走到柜台边，给自己续了一碗茶。他端着茶壶，头也不回地说了一句话。

"想拿粮，拿朝廷的正式批文来。"

张横坐在椅子上，没有说话。过了几息，他站起来。

他比宁观潮高出半个头，站起来的时候像一尊铁塔立在桌边。他低头看着宁观潮，目光里带着毫不掩饰的压迫感。

"六殿下，末将敬你是皇子，好声好气说话。"

他的声音放低了，低到只有两个人能听见的程度。

"但黑石郡的地界上，边军要的粮，还没有拿不到的。"

他身后的一个随从跟着附和了一句，嗓门不小："殿下，这是边关军务！您一个流放之人……"

张横抬手拦住了随从。

他看着宁观潮，声音压得更低，像钝刀子在石头上磨了一下。

"殿下，这是边关军务。您一个流放之人，干涉军务，怕是不太合适。"

客栈里的空气像冻住了一样。福伯站在厨房门口，攥着抹布的手指节发白。两个在角落里吃面的客人放下筷子，悄悄站起来，贴着墙根溜了出去。

宁观潮端着茶碗，没有动。他低头看着碗里浅褐色的茶水，像是在打量一碗跟自己没什么关系的东西。

然后他把碗放下来。放得很轻，杯底碰到桌面，发出一声清脆的声响。

他抬起头，看着张横的眼睛。

"流放之人也是玄曜帝朝的皇子。想拿粮，拿文书来。"

客栈里安静了。

张横的目光在宁观潮脸上停了几息。他的手指在刀柄上搭了一下，又松开了。

他转身。

"走。"

他带着人走出了客栈。马蹄声急促地远去，像一阵闷雷滚过街道。

福伯从厨房里探出头来，脸上还带着没擦干净的面粉，声音压得极低："少爷……边军的人，这是来打秋风的？"

"不是打秋风。"

宁观潮端着茶碗，看着门外扬起的尘土。

"是试探。"

他来黑石城一个多月了。灭赵家，开粮仓，放粮，分地……这些事情，永平关那边不可能不知道。赵家还在的时候，永平关和赵家有利益往来。赵家倒了，永平关的财路断了。他们现在派人来试探，是想看看这个废太子到底好不好拿捏。

给粮食，就是认怂。边军以后会每个月都来要。

不给，就得罪了永平关。以后黑石城的商队经过永平关，都会被刁难。

宁观潮选择了不给。

但他也知道……这只是开始。

边军的人走了没一会儿，宁观潮坐在桌边，把剩下的半碗凉茶喝完。福伯把溜走的两个客人留下的面碗收了，低声问了一句："少爷，他们还会再来吧？"

"会。"

宁观潮站起来，走到窗边，看着街上扬起的尘土还没完全落定。张横走得急，连桌上那份文书都没有收走。他走过去，拿起那份文书翻了翻……格式工整，措辞规范，但确实没有州府的批文印章。

他把文书折好，收进怀里。

留着，以后有用。

第二天一早，沈乌衣的消息就到了。

灰鸽子落在客栈的屋顶上，腿上绑着一根窄纸条。福伯爬上去取下来，递给宁观潮。纸条上的字迹很小，像是用极细的笔在一指宽的纸条上写的：

"永平通运与张横同路。粮市是前哨。"

宁观潮看完，把纸条揉碎在手心里。纸屑从他指缝间落下来，飘散在地上。

永平通运的米铺在前，张横的征粮在后。

不是两件事。

是一件事。

边军的人，比他想得更早就在布局了。这边的人在黑石城刚经历了一场大换血之后，立刻就被人盯上了。他们不急着动武，先派商人来卡粮价，再派校尉来要粮。软的硬的，双管齐下。

宁观潮把掌心里的纸屑拍干净，推开窗。城北赵府的方向，那块被摘下来的匾额还斜靠在墙角，但已经没有人去看了。黑石城的目光，已经转到了城东那家永平通运的米铺上，和城外那条通往永平关的官道上。

宁观潮关上窗，在窗台上轻轻叩了两下。

他转过身。

"福伯，中午多煮两个菜。"

福伯愣了一下。

"下午该干活了。"
